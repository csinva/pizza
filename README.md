# pizza

Hosted at https://csinva.io/pizza/

- [SoHo Pizza Crawl](https://csinva.io/pizza/soho.html) (from `soho_pizza_crawl.pptx`)
- [West Village Pizza Crawl](https://csinva.io/pizza/west-village.html) (from `west_village_pizza_crawl.pptx`)
- [Arthur Avenue Slice Crawl](https://csinva.io/pizza/slice-crawl.html)

The route maps are generated from OpenStreetMap data. After changing stops in `tools/build_maps.py`, rebuild them with `python3 tools/build_maps.py` (add `--refresh` to refetch the map data).
